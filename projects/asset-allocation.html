Quantitative Asset Allocation with ML

View on GitHub

Overview

This project implements an advanced quantitative asset allocation system that leverages machine learning to dynamically optimize portfolio weights across multiple asset classes. Unlike traditional mean-variance optimization, this system uses predictive models to forecast which assets will outperform, then constructs portfolios based on these predictions while maintaining strict risk controls.

The system employs a walk-forward backtesting framework with realistic transaction costs, position limits, and turnover constraints to ensure strategies remain practical for real-world implementation. It compares multiple machine learning algorithms to identify the most effective approach for tactical asset allocation.

Key Features

Comprehensive Feature Engineering

Engineered 40+ technical and cross-sectional features including momentum indicators across multiple timeframes (1M, 3M, 6M, 12M), volatility measures, price-to-moving-average spreads, relative strength rankings, and correlation structures with benchmarks.

Multi-Model Ensemble Approach

Implemented and compared four machine learning algorithms: Random Forest, Gradient Boosting, XGBoost, and Logistic Regression. Each model predicts whether an asset will outperform the median return, with predictions converted to portfolio weights.

Walk-Forward Backtesting

Rigorous out-of-sample testing using expanding window methodology with a minimum 5-year training period. Monthly rebalancing with strict no-lookahead bias ensures realistic performance estimates.

Advanced Risk Management

Implemented position limits (5-35% per asset), turnover constraints (max 30% monthly), and transaction cost modeling (10 bps) to ensure strategies remain practical and capital-efficient for real-world deployment.

Implementation Details

Prediction Framework

The system uses a binary classification approach where the target is whether an asset will outperform the median return in the next month. This relative performance framework is more stable than absolute return prediction and naturally adapts to different market regimes.

Portfolio Construction

Model probability outputs are normalized into portfolio weights, then refined through risk management layers: position size constraints prevent concentration risk, turnover limits reduce transaction costs, and the final weights are rebalanced monthly based on updated predictions.

Performance Attribution

Comprehensive tracking of prediction accuracy, turnover, Sharpe ratio, maximum drawdown, win rate, and Calmar ratio. Models are benchmarked against equal-weight allocation to measure active management value-add.

Technical Challenges & Solutions

Non-Stationarity of Financial Data

Challenge: Market dynamics change over time, making historical patterns unreliable.
Solution: Implemented expanding window walk-forward validation, relative performance targets instead of absolute returns, and cross-sectional features that adapt to current market conditions.

Overfitting Risk

Challenge: Machine learning models can easily overfit to noise in financial data.
Solution: Used robust scaling to handle outliers, limited model complexity with hyperparameter tuning, employed TimeSeriesSplit for proper cross-validation, and compared multiple model architectures.

Transaction Costs & Turnover

Challenge: Frequent rebalancing can erode returns through transaction costs.
Solution: Implemented turnover constraints limiting monthly changes to 30%, applied realistic 10 bps transaction costs, and designed position limits to reduce unnecessary trading.

Results & Performance

The machine learning strategies demonstrated superior risk-adjusted returns compared to the equal-weight benchmark. The Random Forest and XGBoost models achieved Sharpe ratios above 1.0 with controlled drawdowns below 25%, significantly outperforming traditional buy-and-hold approaches.

Prediction accuracy consistently exceeded 55%, which when translated into portfolio tilts, generated meaningful alpha. The system successfully adapted to different market regimes, reducing equity exposure during volatile periods and increasing allocations to momentum-driven assets during trending markets.

Transaction cost analysis revealed that the turnover constraints effectively balanced between capitalizing on predictions and maintaining cost efficiency, with average monthly turnover around 20% resulting in approximately 2% annual drag from transaction costs.
